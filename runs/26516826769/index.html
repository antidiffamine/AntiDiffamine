🧪 AntiDiffamine

This page shows a visual comparison of three views of a force-push: the original Git diff, the 🧪 AntiDiffamine diff, and the 📊 range-diff.

On hetero-ancestral pairs, where the source (before) and target (after) commits of a force-push do not share the same ancestor on their base branch, a plain git diff conflates with branch updates. AntiDiffamine rebases the source range onto the target base to isolate changes within the PR-scope. The git range-diff comparison match and compare ranges of commits pairing using a cost fudge factor (default=60).
